# Cyber Security Project

This repository contains the code, data, and notebooks for the Cyber Security project.

## Structure
```
Cyber_Security_Project/
│
├── notebooks/          # Jupyter notebooks
├── data/
│   ├── raw/            # Original data
│   └── processed/      # Cleaned/processed data
├── scripts/            # Python scripts
├── reports/            # Generated reports
├── images/             # Visualizations and figures
└── models/             # Saved models
```

## How to Use
1. Clone the repository
2. Open the Jupyter notebook in `notebooks/`
3. Follow the steps inside to reproduce results
